# Completed data preprocessing assignment

Open `CKD_data_preprocessing_assignment.ipynb` in Jupyter Notebook or JupyterLab.
The notebook is already executed and contains the full cleaning pipeline, data-frame
displays, statistics, histograms, outlier review, correlation heatmaps, and written
interpretation requested by the assignment.

## Contents

- `CKD_data_preprocessing_assignment.ipynb` — completed assignment
- `data/chronic_kidney_disease.csv` — local copy of the official UCI source CSV
- `uci_metadata.json` — official UCI API metadata captured with the assignment
- `build_notebook.py` — reproducible notebook generator

## Re-run

From this folder, run all cells in the notebook with a Python 3 kernel containing
`pandas`, `numpy`, `matplotlib`, `seaborn`, and `IPython`.

Data source: Rubini, L., Soundarapandian, P., & Eswaran, P. (2015),
*Chronic Kidney Disease*, UCI Machine Learning Repository,
https://doi.org/10.24432/C5G020 (CC BY 4.0).
